# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-08-30

- Added reachability checks for Bilibili web, public API, member API, and static CDN.
- Added dynamic discovery of Bilibili `preupload` candidates.
- Added deduplicated tests for current biliLive-tools UPOS route selectors.
- Added success rate, DNS, TCP, TLS, TTFB, total latency, P95, jitter, grading, and ranking.
- Added optional size-limited public BVID download throughput checks.
- Added IPv4/IPv6 selection, legacy route tests, report output, and safe temporary-file cleanup.
